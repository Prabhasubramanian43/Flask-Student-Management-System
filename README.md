# Flask Student Management System

This project is a simple web application for managing student records using Flask and SQLite.

## Features
- Add new student records
- View student details
- Update student information
- Delete student records

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Bootstrap
- SQLite

## Installation

1. Clone the repository
2. Navigate to the project folder
3. Install Flask

Example:

pip install flask

## Run the Application

Run the following command:

python app.py

Then open your browser and go to:

http://127.0.0.1:5000/

## Project Structure
- app.py
- templates/
- static/
- database.db
